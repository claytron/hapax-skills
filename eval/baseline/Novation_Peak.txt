[COMMENT]
Novation Peak, 8-voice polysynth. Set Peak MIDI channel (MidiChan, Menu page 5) to match OUTCHAN, and CC/NRPN to Receive or Rec+Tran.
Peak uses 14-bit CC pairs (MSB/LSB = CC n / n+32) for osc coarse/fine/LFO2>pitch, mixer levels, filter freq, LFO1>filter and LFO1/2 rate; only the MSB is defined here, giving 7-bit resolution.
Bipolar CCs (shape amounts, env depths, osc tuning) are centred at 64.
Mod Matrix slots 9-16 (NRPN 9:0 to 16:3) omitted to keep the list manageable. Patch category/genre (NRPN 0:0, 0:1) omitted.
Arp clock rate has no MIDI control; sync Peak to Hapax MIDI clock instead.
[/COMMENT]
